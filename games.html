Excel Sheet: Games

To add or edit embedded games without touching code, simply update the Games sheet in data/lessons.xlsx.

Sheet Columns:

  • id: Unique identifier (e.g. game-01, game-02)
  • order: Sequence number (e.g. 1, 2, 3)
  • title: Game title displayed in the card header
  • category: Skill tag (e.g. Tone Practice, Vocabulary)
  • description: Short overview for the learner
  • embed_code: Full iframe snippet (e.g. <iframe src="..." ...></iframe>)
  • embed_url: Or raw URL (e.g. https://wordwall.net/embed/...)
  • active: Set to TRUE to show, FALSE to hide
